# AI미러

폰 전면 카메라를 거울처럼(좌우 반전) 보여주면서 자동으로 보정하는 웹앱.

- 피부결: 피부색 영역에만 경계 보존 블러(bilateral) 적용, 잔결 일부 유지
- 조명: 얼굴 영역 밝기 측정 → 노출·화이트밸런스·암부 들어올림·정면광 효과 자동 조절
- 렌즈 왜곡: 가까이서 찍을 때 가운데(코·볼)가 커 보이는 현상을 살짝 완화
- 화면 조명: 어두우면 화면 테두리를 따뜻한 흰빛으로 바꿔 얼굴을 비춤(자동, 수동 전환 가능)
- 보정 강도 3단계(약하게/보통/강하게), 누르는 동안 원본 비교
- 모든 처리는 기기 안(WebGL)에서만, 저장·전송 없음

## 파일
- `app.html` 앱 본체(소스)
- `sh build.sh` 로 `site/` 에 설치형(PWA) 페이지 생성
- `site/` 를 HTTPS 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 폰에서 실시간 거울로 동작, 홈 화면에 추가 가능

카메라는 HTTPS(또는 localhost)에서만 열리므로 실시간 모드는 호스팅이 필요하다.
